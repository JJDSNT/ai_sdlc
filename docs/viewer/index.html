AI_context viewer

Visualiza issues, specs e consolidated de qualquer repositório GitHub que siga a convenção AI_context/ — direto do navegador, sem clonar nada.

Token não é salvo em nenhum lugar — fica só em memória enquanto a página está aberta. Sem token, a API do GitHub limita a 60 requisições/hora.
